#  CHANGELOG

Todos los cambios relevantes del proyecto **EAFITos Shell** serán documentados en este archivo.

El formato está inspirado en *Keep a Changelog* y el proyecto sigue un versionado académico.

---

## [1.0.0] - 2026-02-23

###  Added
- Implementación inicial del shell personalizado.
- Soporte para ejecución de comandos básicos del sistema.
- Implementación de 10 comandos personalizados.
- Estructura modular separada en:
  - `include/`
  - `src/`
  - `tests/`
- Creación de pruebas unitarias e integración.
- Script automatizado para ejecución de pruebas.
- Archivo README con documentación general del proyecto.

###  Improved
- Mejora en formato y organización del README.
- Optimización en separación de responsabilidades por módulos.
- Validaciones adicionales en comandos.
- Organización interna del flujo de ejecución del shell.

###  Testing
- Implementación de pruebas unitarias.
- Implementación de pruebas de integración.
- Validación manual de comandos implementados.

###  Cleanup
- Eliminación de archivos innecesarios (`nuevo.txt`, `prueba.txr`).
- Reestructuración final del repositorio según arquitectura recomendada.
- Organización de documentación complementaria.
- Actualización de CONTRIBUTORS.md.
